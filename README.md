Network Reconnaissance Lab (Kali Linux)

Overview
This project demonstrates basic network reconnaissance using Kali Linux and Nmap in a controlled VMware virtual environment.

---

Objective
- Perform host discovery on a local virtual network  
- Identify active devices and network structure  
- Practice ethical cybersecurity techniques  

---

Tools Used
- Kali Linux  
- Nmap  
- VMware Workstation / VirtualBox  

---

Network Info
